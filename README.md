# Analise de 20 Numeros em C

Programa feito em linguagem C que analisa 20 numeros inteiros.

## O que o programa faz:
- Le 20 numeros digitados pelo usuario
- Soma dos multiplos de 3
- Soma e quantidade de numeros pares
- Quantidade de positivos e negativos
- Maior e menor numero
- Media dos numeros pares

## Como compilar e executar:
gcc main.c -o main
./main
